# AyuGram Desktop (Custom Minimal Linux Edition)

Кастомная, легковесная и безопасная сборка клиента Telegram / AyuGram для **Linux Mint** и других дистрибутивов на базе Linux.

Сборка полностью очищена от маркетинговых и крипто-функций Telegram, фоновой телеметрии и сторонних сетевых запросов, а также оснащена мощными инструментами для поиска, навигации по цепочкам ответов и адаптивного отображения контента.

---

## ✨ Ключевые возможности

### 🔍 1. Продвинутый поисковый движок (Smart Search)
- **Звездочки и Wildcards (`*`, `.*`)**: 
  - `обновл*` — найдет *обновлять*, *обновление*, *обновленный*.
  - `авто.*тест` — найдет любые фразы, где между «авто» и «тест» произвольное количество символов (*автотест*, *автоматический тест*).
- **Исключения и Минус-слова (`-слово`, `-"фраза"`)**:
  - `купить -дорого` — найдет сообщения со словом «купить», исключив содержащие «дорого».
  - `сервер -"технические работы"` — исключит сообщения с точной фразой.
- **Точные кавычки (`"дословная фраза"`)**:
  - `"ошибка подключения к базе"` — строгий поиск точной фразы с сохранением порядка слов.
- **Логическое ИЛИ / Альтернативы (`A|B|C`)**:
  - `обновлять|заменять` — извлекает кандидатов по всем ключевым словам с сервера Telegram и ищет сообщения с любым из указанных слов.
- **Регулярные выражения (RegEx)**:
  - Поддержка синтаксиса `/шаблон/flags` и префикса `regex:шаблон` с флагами регистра.
- **Морфологический поиск (RU/EN)**:
  - Встроенный стеммер Портера находит формы слов независимо от падежей и склонений (*купить -> купил, покупка, куплю*).
- **Поиск по папкам чатов**:
  - Поиск строго внутри активной папки чатов без примешивания посторонних каналов.

---

### 🌲 2. Универсальная навигация по веткам ответов (Reply Threads)
- **Для личных сообщений (ЛС) и малых групп**: встроенный клиентский движок навигации формирует нативное дерево ответов прямо на клиенте без ошибок Telegram API.
- **Для каналов и супергрупп**: штатная подгрузка комментариев и веток обсуждений через серверное API Telegram (`MTPmessages_GetReplies`).

---

### 📐 3. Адаптивная широкая верстка сообщений (Wide Post Layout)
- Облачка сообщений и медиа-вложения адаптивно масштабируются **до 85% ширины экрана**, устраняя пустоты по краям на мониторах высокого разрешения.
- Исправлены расчеты высоты блоков (`maxWithCaption` и `monospace block`), исключающие наложения постов друг на друга при наличии картинок и длинного текста под ними.
- Встроенный инструмент создания скриншотов **Message Shot** выполняет точный пересчет геометрии.

---

### 🛡️ 4. Безопасность, приватность и очистка от мусора

| Компонент / Функция | Статус | Описание |
| :--- | :---: | :--- |
| **`RCManager`** | ❌ Удален | Нейтрализованы периодические сетевые запросы к сторонним серверам за бейджами, каналами авторов и кошельками. |
| **Телеметрия и Sentry** | ❌ Удалены | Отключены сбор метрик, отправка отчетов об ошибках и аналитика. |
| **Чекер автообновлений** | ❌ Отключен | Клиент изолирован и не скачивает сторонние исполняемые файлы. |
| **Сторонние сервисы** | ❌ Удалены | Вырезаны обращения к `dpaste.com` (экспорт фильтров переведен в локальный буфер обмена) и `itunes.apple.com`. |
| **Сторисы (Stories)** | ❌ Отключены | Панель историй, предпросмотры и уведомления о сторисах полностью скрыты. |
| **Подарки, Звезды, TON** | ❌ Отключены | Полностью убраны элементы криптоинтеграции, донатов, платных реакций и подарков. |
| **Фикс удаленных сообщений**|  Исправлен | Корректно сохраняются сообщения в топиках (Issue #454) и самоудаляемые сообщения (Issue #424). |
| **Системный браузер** |  Включен | Внешние ссылки открываются в системном браузере по умолчанию (без встроенного Webview). |
| **Локальная история** |  Включена | Сохранение удаленной истории в локальную базу SQLite (`ayudata.db`) на вашем ПК без отправки во внешнюю сеть. |

## 📦 Установка и запуск

### Скачивание готового релиза

1. Скачайте свежий релиз со страницы **[Releases](https://github.com/darakcheeff/AyuGramDesktop/releases)**.
2. Распакуйте и запустите:
   ```bash
   tar -xf AyuGram-Linux-Custom.tar.xz
   chmod +x AyuGram
   ./AyuGram
   ```

---

## 🛠️ Сборка из исходного кода

Сборка выполняется автоматически через Docker в среде `centos_env` (совместима с glibc любых современных версий Linux Mint / Ubuntu):

```bash
# 1. Клонирование репозитория
git clone --recursive https://github.com/darakcheeff/AyuGramDesktop.git
cd AyuGramDesktop

# 2. Сборка автономного бинарника
docker run --rm \
    -u $(id -u) \
    -v "$PWD:/usr/src/tdesktop" \
    ghcr.io/telegramdesktop/tdesktop/centos_env:latest \
    /usr/src/tdesktop/Telegram/build/docker/centos_env/build.sh \
    -D TDESKTOP_API_ID=2040 \
    -D TDESKTOP_API_HASH=b18441a1ff607e10a989891a5462e627 \
    -D TDESKTOP_DISABLE_AUTOUPDATE=ON
```
