### 🔍 Подробное описание билда `v7.0.9-custom-b5`

1. **Зачистка настроек от коммерческих элементов**:
   - В `settings_main.cpp` полностью удалены пункты «Звёзды Telegram», «Валюта / TON» и «Подарить Premium».
2. **Отключение сетевых запросов и фоновой предзагрузки Stories**:
   - В `data_stories.cpp` заблокированы методы `loadMore()`, `continuePreloading()`, `startPreloading()`, `incrementPreloadingMainSources()` и `requestReadTills()`, исключая расход трафика и памяти на сторис.
3. **Исправление объединения результатов поиска (16.png, 17.png)**:
   - В `dialogs_widget.cpp` для запросов с `|` результаты всех слов объединяются в общий список без затирания. В `dialogs_inner_widget.cpp` внедрена сортировка по дате.
4. **Серверные треды каналов и пагинация по скроллу (14.png, 15.png)**:
   - В `data_replies_list.cpp` внедрен метод `isServerThread()`: для комментариев каналов включена полноценная серверная пагинация при скролле.
5. **Клиентские локальные ветки для «свободного общения»**:
   - Для обычных сообщений участников в группах, ЛС и базовых чатах сохранено построение локального дерева ответов.

6. **Неограниченное количество локальных папок и облачная синхронизация**:
   - При превышении лимита папок сервера (10 для обычных пользователей / 30 для Premium), все дополнительные папки создаются как локальные (`id >= 1000`) без блокировки интерфейса и без вызова пейволла.
   - Реализована надёжная синхронизация папок между устройствами пользователя через приватный беззвучный канал-хранилище (`⚙️ AyuGram Sync Storage`) с тегом `#ayugram_sync_folders`.
   - **Гарантированное размещение канала в Архиве**: при создании и синхронизации канал автоматически архивируется через API (`toggleHistoryArchived`), заглушается навсегда и скрывается из основного списка чатов.
   - **Надёжное обнаружение и сохранение ID**: канал ищется непосредственно в списке диалогов Архива и основного списка, а его `channelId` персистентно сохраняется в локальном конфиге для мгновенного восстановления без лишних сетевых запросов.
   - **Ручная синхронизация в Настройках**: в разделе *Настройки -> Папки* добавлена кнопка «Синхронизировать папки в архивный канал» с мгновенным всплывающим уведомлением (Toast).
   - **Автобэкап всех папок**: синхронизация выполняется при наличии любых пользовательских папок, обеспечивая резервное копирование и появление архивного канала сразу после настройки папок.

7. **Мониторинг сообщений и фильтрация по ключевым словам / Regex (Watchers)**:
   - Внедрена система правил мониторинга входящих сообщений (как глобально по всем чатам, так и с привязкой к конкретному каналу/группе).
   - Для каждого правила настраиваются независимые действия:
     - **Уведомление в обход беззвучного режима**: мгновенный звук и всплывающий пуш даже из заглушенных каналов и групп (`AyuWatchers::ShouldBypassMute`).
     - **Сводка в «Избранное»**: формирование и отправка карточки со ссылкой на исходное сообщение (`https://t.me/...`).
     - **Счётчик срабатываний**: подсчёт количества совпадений для каждого правила с кнопкой сброса.
     - **Webhook (HTTP POST в n8n)**: отправка детального JSON-пакета со всеми метаданными сообщения на внешний вебхук (с возможностью мгновенного тестирования связи прямо из интерфейса).
   - Удобное управление: вызов из контекстного меню чата («🔔 Мониторинг ключевых слов...»), из контекстного меню любого выделенного сообщения («🔔 Добавить в мониторинг...»), а также из общего меню *Настройки AyuGram -> Фильтры*.

8. **Поиск всех сообщений пользователя и подписка на посты (User Watchers & Cross-chat Search)**:
   - **Поиск в текущем чате в 1 клик**: пункт «🔍 Сообщения автора в этом чате» добавлен в контекстное меню любого сообщения без привязки к скрытым настройкам и без ограничений по типу чата (работает в супергруппах, каналах, темах-топиках и комментариях).
   - **Кросс-чат поиск по общим группам (`ShowUserGlobalSearchBox`)**: специальное окно, автоматически запрашивающее список общих чатов с пользователем через `MTPmessages_GetCommonChats` и выполняющее поиск его сообщений с выводом быстрых кнопок перехода в поиск по автору в каждой общей группе в 1 клик, превью сообщений, даты и мгновенным переходом к конкретному сообщению в истории.
   - **Подписка на посты автора (User Watchers)**: интеграция с системой Watchers, позволяющая отслеживать любые сообщения конкретного человека (или только содержащие ключевые слова), с обходом беззвучного режима, сохранением в «Избранное», подсчётом активности и отправкой Webhook в n8n.

9. **Локальная оффлайн-база сообщений и оффлайн-режим (Offline Database & Search)**:
   - **Автоматическое фоновое сохранение входящих сообщений**: при наличии сети каждое новое входящее сообщение проверяется правилами мониторинга и асинхронно сохраняется в локальную базу SQLite (`LocalMessage`) без блокировки интерфейса (`crl::async`).
   - **Оффлайн-просмотр истории диалогов**: если сеть недоступна или запрос к серверу завершается с ошибкой (`messagesFailed`), клиент автоматически подгружает сохранённую историю из локальной базы данных (`getLocalMTPMessages`), позволяя полноценно открывать и читать чаты без интернета.
   - **Локальный оффлайн-поиск сообщений**: при отсутствии подключения или сбое поиска на сервере поиск в списке диалогов мгновенно переключается на локальную базу данных SQLite (`searchLocalFallback`), находя сообщения по тексту с преобразованием в нативные `MTPMessage`.
   - **Управление базой**: в *Настройки AyuGram -> Прочее* добавлена кнопка «Очистить локальную базу сообщений» с подтверждением.
